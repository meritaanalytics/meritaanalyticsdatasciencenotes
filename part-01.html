Part 1

What Is Data Science?

The big picture before any code: what data scientists do, the workflow they follow, and the path through this handbook.

In this part
  • What data science is, and how analyst, scientist and engineer roles differ
  • The workflow every data project follows
  • Which tool to use for which job
  • The 32-week path through this handbook
You need first NothingTime 1 hour

#1.1 What is data science?

Data science is the practice of turning data into decisions. A shop owner who looks at last month's sales to decide what to restock is doing a small version of it. Data science adds tools that scale: code to clean millions of rows, statistics to tell real patterns from luck, and machine learning to make predictions.

Role Main question Typical tools
Data analyst What happened and why? SQL, Excel, Power BI, Python
Data scientist What will happen, and what should we do? Python, statistics, machine learning
Machine learning engineer How do we run models reliably for users? Python, deployment, monitoring
Credit risk analyst Who is likely to repay? SQL, Python, scorecards

This handbook starts where an analyst starts and ends where a machine learning practitioner works, so you can stop at the level your job needs.

#1.2 The workflow

Every project, big or small, loops through the same steps. Notice that modelling is only one of them: most of the time goes into understanding and preparing data.

steps = ["1 Ask a clear question", "2 Get the data", "3 Clean and check it", "4 Explore it",
         "5 Model or test", "6 Judge the result honestly", "7 Tell the story", "8 Deploy and monitor"]
for s in steps:
    print(s)

1 Ask a clear question
2 Get the data
3 Clean and check it
4 Explore it
5 Model or test
6 Judge the result honestly
7 Tell the story
8 Deploy and monitor

#1.3 Which tool for which job?

Job Best tool Part
Quick look at a small table Excel 17
Pull and summarise data from a database SQL 6
Clean, reshape and analyse tables Python with pandas 4
Charts for yourself or a report matplotlib and seaborn 5
Interactive dashboards for managers Power BI 17
Predictions and patterns scikit-learn, then deep learning 9 to 16

Rule of thumb. Heavy joins in SQL; cleaning, statistics and modelling in Python; presentation in Power BI; one-off checks in Excel.

#1.4 A first taste

Do not worry about the syntax yet; every line is explained in the next parts. Read it like a story: make a tiny table, then answer a question with it.

import pandas as pd
sales = pd.DataFrame({"item": ["maize flour", "sugar", "cooking oil", "rice"],
                      "units": [30, 18, 12, 25], "price_ksh": [150, 180, 320, 210]})
sales["revenue_ksh"] = sales.units * sales.price_ksh
print(sales.sort_values("revenue_ksh", ascending=False))
print("Best seller by revenue:", sales.loc[sales.revenue_ksh.idxmax(), "item"])

          item  units  price_ksh  revenue_ksh
3         rice     25        210         5250
0  maize flour     30        150         4500
2  cooking oil     12        320         3840
1        sugar     18        180         3240
Best seller by revenue: rice

#1.5 The 32-week path

The table below is a suggested pace at 8 to 10 hours a week. Each level ends with a project, because you learn most by building.

import pandas as pd
path = pd.DataFrame([
 ("1 Foundations",              "1-3",   1,  4, "Python and NumPy exercises"),
 ("2 Data Analysis",            "4-7",   5, 10, "Project 1: shop sales analysis"),
 ("3 Statistics",               "8",    11, 13, "A/B test write-up"),
 ("4 Machine Learning",         "9-13", 14, 21, "Project 7: loan default model"),
 ("5 Deep Learning, RL, GenAI", "14-16", 22, 26, "A small neural network and a RAG demo"),
 ("6 The Real World",           "17-19", 27, 30, "Projects 8 and 9, deployment"),
 ("7 Career and Reference",     "20-22", 31, 32, "Exercises and mock interview"),
], columns=["level", "parts", "week_from", "week_to", "milestone"])
path["weeks"] = path.week_to - path.week_from + 1
print(path[["level", "parts", "weeks", "milestone"]].to_string(index=False))
print("total weeks:", path.weeks.sum())

#1.6 Habits that make you good

  • Question first. Write the business question in one sentence before you open the data.
  • Check before you trust. Count rows, look at missing values, reconcile totals.
  • Explain simply. If you cannot explain a result to a shopkeeper, you do not understand it yet.
  • Be honest about limits. Say what the data cannot show.
  • Keep a portfolio. Save each project to GitHub with a short README.
Key takeaways
  • Data science turns data into decisions; modelling is one step of an eight-step loop.
  • Pick the tool for the job: SQL, pandas, Power BI, or machine learning.
  • This handbook climbs from Python basics to deep learning and LLMs, one level at a time.
  • Build a project at the end of each level.
