Part 5

Data Visualisation

A picture finds the trend, the outlier and the gap in seconds, where a table of hundreds of rows hides them. This Part teaches the anatomy of a chart, the five core chart types, how to choose between them, subplots, seaborn statistical plots, annotation, saving and the most common chart mistakes, then applies it all to real public data.

In this part
  • Build a complete, labelled chart with matplotlib (figure, axes, title, labels, formatter)
  • Draw line, bar, histogram, box and scatter charts and know what each one answers
  • Pick the right chart from the question you are asking
  • Use subplots and seaborn to compare groups quickly
  • Annotate, save and sanity-check a chart so it can go in a report
You need first Part 4Time 3 to 4 hours

#5.1 Anatomy of a figure

Matplotlib is the drawing engine of Python analytics. Seaborn sits on top of it and draws statistical charts from a table in one line. A matplotlib picture is a Figure (the canvas) holding one or more Axes (one chart with its own x and y axis). Always use the object style: fig, ax = plt.subplots() and then ax.plot(...). You always know which chart a command belongs to.

Most examples in this section use a small synthetic table of 500 orders from an electronics and accessories shop. The prices are illustrative and describe no real business.

import numpy as np, pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

BLUE, GREEN, GREY, DARK, AMBER = "#1F5FD6", "#2BB38A", "#9CA3AF", "#0B2A4A", "#B45309"
sns.set_theme(style="whitegrid", rc={"axes.titleweight": "bold", "axes.titlesize": 11})

rng = np.random.default_rng(7)
n = 500
shop = pd.DataFrame({
    "order_date": pd.to_datetime("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
    "branch": rng.choice(["Nairobi CBD", "Eastleigh", "Thika", "Nakuru"], n, p=[.4, .3, .15, .15]),
    "category": rng.choice(["TV parts", "Chargers", "Cables", "Speakers"], n, p=[.35, .25, .25, .15]),
    "units": rng.integers(1, 12, n),
})
base = {"TV parts": 4200, "Chargers": 900, "Cables": 350, "Speakers": 2600}
shop["unit_price"] = (shop["category"].map(base) * rng.normal(1, 0.12, n)).round(0)
shop["revenue"] = shop["units"] * shop["unit_price"]
shop["month"] = shop["order_date"].dt.to_period("M").dt.to_timestamp()
print(shop.shape)
shop.head(3)

Canvas size plt.subplots(figsize=(10, 3.6)) width x height in inches
Title ax.set_title(...) say what is measured and when
Axis labels ax.set_xlabel(...) always include units (Ksh, %, count)

Here is the smallest complete chart: total revenue by branch. Raw money axes show numbers like 1e6, which are hard to read, so we add a formatter, a tiny function that turns each tick value into text.

from matplotlib.ticker import FuncFormatter

def ksh_millions(x, pos):
    return f"{x / 1e6:,.1f}M"

def ksh_thousands(x, pos):
    return f"{x / 1e3:,.0f}K"

by_branch = shop.groupby("branch")["revenue"].sum().sort_values(ascending=False)
fig, ax = plt.subplots(figsize=(10, 3.4))
bars = ax.bar(by_branch.index, by_branch.values, color=[BLUE, GREEN, GREEN, GREEN])
ax.yaxis.set_major_formatter(FuncFormatter(ksh_millions))
ax.bar_label(bars, labels=[f"Ksh {v / 1e6:,.2f}M" for v in by_branch.values], padding=3)
ax.set_ylim(0, by_branch.max() * 1.15)
ax.set_title("Total 2025 revenue by branch (synthetic shop)")
ax.set_xlabel("Branch"); ax.set_ylabel("Revenue (Ksh millions)")
plt.tight_layout()
plt.savefig("p05_anatomy.png", dpi=130)
plt.close()
print("saved p05_anatomy.png")

saved p05_anatomy.png

A title that says what is measured, labelled axes with units, direct value labels and one highlighted bar: the reader needs no gridline arithmetic.

Rule. Write one sentence first: the question this chart answers. If you cannot write it, you do not need the chart yet.

#5.2 Line and bar charts: trends and comparisons

Use a line chart for change over time: the line joins points that belong together in sequence, so time goes on the x axis. Use a bar chart to compare categories: bar length encodes the value, so it must start at zero. Sort bars from largest to smallest unless the categories have a natural order such as months.

monthly = shop.groupby("month")["revenue"].sum()
by_cat = shop.groupby("category")["revenue"].sum().sort_values()
print("peak month:", monthly.idxmax().strftime("%b %Y"), f"Ksh {monthly.max():,.0f}")
print("largest category:", by_cat.index[-1], f"Ksh {by_cat.iloc[-1]:,.0f}")

fig, ax = plt.subplots(1, 2, figsize=(10, 3.6))
ax[0].plot(monthly.index, monthly.values, color=BLUE, marker="o", linewidth=2)
ax[0].yaxis.set_major_formatter(FuncFormatter(ksh_thousands))
ax[0].set_title("Monthly revenue, 2025")
ax[0].set_xlabel("Month"); ax[0].set_ylabel("Revenue (Ksh thousands)")
ax[0].tick_params(axis="x", rotation=45)
ax[1].barh(by_cat.index, by_cat.values, color=[GREEN, GREEN, GREEN, BLUE])
ax[1].xaxis.set_major_formatter(FuncFormatter(ksh_millions))
ax[1].set_title("Revenue by category, 2025")
ax[1].set_xlabel("Revenue (Ksh millions)"); ax[1].set_ylabel("Category")
plt.tight_layout()
plt.savefig("p05_line_bar.png", dpi=130)
plt.close()
print("saved p05_line_bar.png")

peak month: May 2025 Ksh 712,464
largest category: TV parts Ksh 4,542,275
saved p05_line_bar.png

The left chart answers how did sales move? and the right chart answers which category is largest? A line through categories would imply an order that does not exist. A horizontal bar (barh) keeps long category names readable.

To compare the mix across groups of different size, convert counts to shares that sum to 100 for each group.

cb = shop.pivot_table(index="branch", columns="category", values="revenue", aggfunc="sum")
share = cb.div(cb.sum(axis=1), axis=0) * 100
print(share.round(1).to_string())
print("each branch sums to 100:", bool(np.allclose(share.sum(axis=1), 100)))

Common mistake. Plotting a time series in the order the rows happen to be stored. Sort by date first (sort_index()), or the line zigzags back and forth.

#5.3 Histogram and box plot: distributions and outliers

A distribution shows how often each value occurs. A histogram cuts the range into bins and counts rows in each. A box plot squeezes the distribution into five numbers: the box runs from the first quartile (Q1) to the third (Q3), the line inside is the median, whiskers reach to 1.5 x IQR from the box, and dots beyond are flagged points. A flagged point is a candidate outlier, not an error.

rev = shop["revenue"]
q1, med, q3 = rev.quantile([.25, .5, .75])
fence = q3 + 1.5 * (q3 - q1)
print(f"median Ksh {med:,.0f} | mean Ksh {rev.mean():,.0f} | flagged above fence: {int((rev > fence).sum())}")

fig, ax = plt.subplots(1, 2, figsize=(10, 3.6))
ax[0].hist(rev, bins=30, color=BLUE, edgecolor="white")
ax[0].axvline(med, color=DARK, linestyle="--", label="median")
ax[0].axvline(rev.mean(), color=AMBER, linestyle="--", label="mean")
ax[0].legend()
ax[0].set_title("Distribution of order revenue")
ax[0].set_xlabel("Order revenue (Ksh)"); ax[0].set_ylabel("Number of orders")
order = ["TV parts", "Speakers", "Chargers", "Cables"]
sns.boxplot(data=shop, x="category", y="revenue", order=order, color=GREEN, ax=ax[1])
ax[1].set_title("Order revenue by category")
ax[1].set_xlabel("Category"); ax[1].set_ylabel("Order revenue (Ksh)")
plt.tight_layout(); plt.savefig("p05_dist.png", dpi=130); plt.close()
print("saved p05_dist.png")

median Ksh 8,900 | mean Ksh 13,724 | flagged above fence: 4
saved p05_dist.png

The histogram is right-skewed: a few big orders drag the mean (amber) above the median (dark), so for money amounts report the median. The box plot shows that spread differs by category. Try two or three bin counts: too few hide the shape, too many draw noise. For very skewed money data a log scale on the axis often gives the clearest picture.

Common mistake. Deleting every dot on a box plot as an error. First check whether it is a data-entry slip (an extra zero) or a genuine large sale.

flagged = shop[rev > fence]
print(flagged["category"].value_counts().to_dict())

{'TV parts': 4}

Flagged orders sit in the higher-priced categories, which suggests large genuine sales rather than errors.

#5.4 Scatter plot and correlation: relationships

A scatter plot puts one row at each (x, y) position and shows whether two numeric columns move together. The correlation coefficient r summarises a straight-line relationship from -1 (perfect opposite) to +1 (perfect together); 0 means no straight-line pattern. Correlation is not cause, and r misses curved patterns, so always look at the plot as well as the number.

rng2 = np.random.default_rng(21)
age = rng2.integers(18, 65, 400)
spend = 6000 + 150 * age + rng2.normal(0, 2500, 400)
cust = pd.DataFrame({"age": age, "monthly_spend": spend})
slope, intercept = np.polyfit(cust["age"], cust["monthly_spend"], 1)
r = cust["age"].corr(cust["monthly_spend"])
print(f"slope: Ksh {slope:,.0f} per year of age | r = {r:.2f} | r squared = {r**2:.2f}")

fig, ax = plt.subplots(figsize=(10, 3.4))
ax.scatter(cust["age"], cust["monthly_spend"], s=14, color=BLUE, alpha=0.45)
xs = np.array([18, 64])
ax.plot(xs, intercept + slope * xs, color=AMBER, linewidth=2)
ax.yaxis.set_major_formatter(FuncFormatter(ksh_thousands))
ax.set_title("Monthly spend against customer age (synthetic)")
ax.set_xlabel("Age (years)"); ax.set_ylabel("Monthly spend (Ksh thousands)")
plt.tight_layout(); plt.savefig("p05_scatter.png", dpi=130); plt.close()
print("saved p05_scatter.png")

slope: Ksh 134 per year of age | r = 0.59 | r squared = 0.35
saved p05_scatter.png

The amber line is the least-squares fit (Part 10 explains it) and r squared is the share of the variation in spend that the line accounts for. When thousands of points overlap, lower alpha (transparency) so dense areas look darker.

Common mistake. Reading r near 0 as 'no relationship'. A perfect U-shape has r close to 0.

x = np.linspace(-3, 3, 200)
print("r for a perfect U-shape (y = x squared):", abs(round(np.corrcoef(x, x ** 2)[0, 1], 3)))

r for a perfect U-shape (y = x squared): 0.0

#5.5 Choosing the right chart

Start from the question, not from a gallery of chart types. Most business questions fall into a few families.

Question Chart Notes
How did it change over time? Line time on x; few lines
Which group is biggest? Sorted bar start the axis at zero
What do the values look like? Histogram try several bin counts
Which group varies more? Box or violin log scale if skewed
Do two measures move together? Scatter (+ trend line) colour by a third column
Which measures are related? Correlation heatmap not cause
What is each part's share? Stacked or 100% bar avoid pies with many slices
Are we meeting a target? Bar plus target line colour only the breaches

Before you share any chart, check six things: the question is stated, the title says what is measured and when, both axes have units, bars start at zero, the one important thing is highlighted, and it still reads in greyscale.

Practice

A lender asks which of five loan products has the highest default rate, and whether late payments cluster in certain months. Name a chart for each.

print("default rate by product -> sorted bar chart, rate labelled, axis from 0")
print("late payments by month  -> line chart over the months")

default rate by product -> sorted bar chart, rate labelled, axis from 0
late payments by month  -> line chart over the months

Solution. A ranking of categories is a sorted bar; a question about time is a line.

#5.6 Subplots and layout

plt.subplots(rows, cols) creates a grid of axes and returns fig and an array ax (one-dimensional for a single row, two-dimensional for a grid). sharex=True and sharey=True give every panel the same scale so panels compare fairly. A set of the same chart for each group is called small multiples.

branches = ["Nairobi CBD", "Eastleigh", "Thika", "Nakuru"]
fig, axes = plt.subplots(2, 2, figsize=(10, 5), sharex=True, sharey=True)
for ax, b in zip(axes.ravel(), branches):
    m = shop[shop["branch"] == b].groupby("month")["revenue"].sum()
    ax.plot(m.index, m.values, color=BLUE, linewidth=1.8)
    ax.set_title(b)
    ax.yaxis.set_major_formatter(FuncFormatter(ksh_thousands))
    ax.tick_params(axis="x", rotation=45)
fig.supxlabel("Month, 2025"); fig.supylabel("Revenue (Ksh thousands)")
fig.suptitle("Monthly revenue by branch, same scale in every panel", fontweight="bold")
plt.tight_layout(); plt.savefig("p05_multiples.png", dpi=130); plt.close()
print("saved p05_multiples.png | axes grid shape:", axes.shape)

saved p05_multiples.png | axes grid shape: (2, 2)

Because the y axis is shared, a branch that looks small really is smaller, not just drawn at a different zoom. Remove sharey=True only when you want to compare shape rather than size. For panels of unequal size use fig.add_gridspec.

Common mistake. With one row of panels ax[0, 1] fails because ax is one-dimensional. Use ax[1], or pass squeeze=False so ax is always two-dimensional.

fig, ax = plt.subplots(1, 2)
ax[0, 1]
Error on purposeIndexError: too many indices for array: array is 1-dimensional, but 2 were indexed

#5.7 Seaborn statistical plots

Seaborn takes a table plus column names (data=, x=, y=, hue=) and does the grouping and statistics for you. Axes-level functions (histplot, boxplot, violinplot, heatmap) draw on an axes you pass with ax=. Figure-level functions (pairplot, displot, catplot) make their own figure. hue splits by a third column.

For these plots we use real public data: the Palmer penguins table (344 penguins of three species, CC0 licence, Horst, Hill and Gorman). A few measurements are missing, so we drop incomplete rows for plotting.

import os
import numpy as np, pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from pathlib import Path

BLUE, GREEN, GREY, DARK, AMBER = "#1F5FD6", "#2BB38A", "#9CA3AF", "#0B2A4A", "#B45309"
sns.set_theme(style="whitegrid", rc={"axes.titleweight": "bold", "axes.titlesize": 11})
PUB = Path(os.environ["GUIDE_ROOT"]) / "datasets" / "public"
def load_public(name, url=None):
    p = PUB / name
    return pd.read_csv(p if p.exists() else url)

peng = load_public("penguins.csv",
                   "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/penguins.csv")
pg = peng.dropna().reset_index(drop=True)
print(len(peng), "rows;", len(pg), "complete rows")
print(pg["species"].value_counts().to_dict())

The histogram with a KDE curve (a smoothed outline) shows that one species is clearly heavier. The violin plot is a box plot that also shows the shape: the wider the violin at a height, the more penguins have that flipper length. The lines inside mark the quartiles.

A pair plot draws every pair of numeric columns, with distributions on the diagonal. It is a first look at a new table, not a finished chart; with more than about six columns it becomes unreadable.

cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g", "species"]
g = sns.pairplot(pg[cols], hue="species", palette=sp_pal, height=1.9, diag_kind="kde",
                 plot_kws={"s": 14, "alpha": 0.7})
g.figure.suptitle("Penguin measurements, every pair of columns", y=1.02, fontweight="bold")
g.figure.savefig("p05_pair.png", dpi=110, bbox_inches="tight")
plt.close(g.figure)
print("saved p05_pair.png")

saved p05_pair.png

Each species forms its own cluster in several panels, and Gentoo separates most clearly. Colouring by group is what reveals this; a single colour would show one confusing blob.

A heatmap colours a table of numbers. With a correlation matrix, use a diverging palette centred on 0 so positive and negative relationships look different.

corr = pg[["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]].corr()
within = (pg.groupby("species")[["bill_length_mm", "bill_depth_mm"]].corr()
          .xs("bill_length_mm", level=1)["bill_depth_mm"].round(2))
print("bill depth vs length, all penguins:", round(corr.loc["bill_length_mm", "bill_depth_mm"], 2))
print("same correlation inside each species:", within.to_dict())

fig, ax = plt.subplots(figsize=(6.5, 4.2))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="vlag", center=0, vmin=-1, vmax=1, ax=ax)
ax.set_title("Correlation between penguin measurements")
plt.tight_layout(); plt.savefig("p05_heatmap.png", dpi=130); plt.close()
print("saved p05_heatmap.png")

bill depth vs length, all penguins: -0.23
same correlation inside each species: {'Adelie': 0.39, 'Chinstrap': 0.65, 'Gentoo': 0.65}
saved p05_heatmap.png

Overall, bill depth is weakly negative against bill length, yet inside each species the correlation is positive. Mixing groups can reverse a trend (this is called Simpson's paradox), so colour or split by group before you believe a correlation.

#5.8 Annotation and styling: point at the one thing to notice

A chart without a point is wallpaper. Decide the single message, then use colour and text so the reader sees it first. Tools: ax.annotate(text, xy=..., xytext=..., arrowprops=...) for a labelled arrow, ax.axhline and ax.axvline for reference lines, ax.axvspan for a shaded period. Use grey for the context and one accent colour (amber) for the point. Build the label text from the data with an f-string so it can never disagree with the chart.

from matplotlib.ticker import FuncFormatter
rng = np.random.default_rng(5)
months = pd.date_range("2025-01-01", periods=12, freq="MS")
sales = pd.Series(60 + rng.normal(0, 6, 12) + [0, 0, 0, 5, 0, 0, 0, 8, 0, 0, 0, 30], index=months)
best, avg = sales.idxmax(), sales.mean()
print("peak:", best.strftime("%B"), f"Ksh {sales.max():.0f}K | average Ksh {avg:.0f}K (synthetic)")

fig, ax = plt.subplots(figsize=(10, 3.6))
ax.plot(sales.index, sales.values, color=GREY, linewidth=2)
ax.scatter([best], [sales.max()], color=AMBER, s=70, zorder=3)
ax.axhline(avg, color=DARK, linestyle="--", linewidth=1)
ax.text(sales.index[0], avg + 1.5, "monthly average", fontsize=9, color=DARK)
ax.annotate(f"Peak: {best.strftime('%B')}, Ksh {sales.max():.0f}K", xy=(best, sales.max()),
            xytext=(sales.index[6], sales.max() - 3), color=AMBER, fontweight="bold",
            arrowprops={"arrowstyle": "->", "color": AMBER})
ax.set_ylim(0, sales.max() * 1.15)
ax.set_title("Monthly sales of a shop, 2025: one peak stands out (synthetic)")
ax.set_xlabel("Month"); ax.set_ylabel("Sales (Ksh thousands)")
plt.tight_layout(); plt.savefig("p05_annotated.png", dpi=130); plt.close()
print("saved p05_annotated.png")

peak: December Ksh 83K | average Ksh 63K (synthetic)
saved p05_annotated.png

Grey context, one amber point, a dashed average and a title that names the finding: that is the whole recipe. For colour choices, remember that about one man in twelve has some colour-vision deficiency. Vary lightness as well as hue, add markers or direct labels so a legend is not the only key, and prefer palettes such as "colorblind", "viridis" (ordered data) or "vlag" (diverging) over rainbow colormaps like jet.

Data type Palette type Example
Categories with no order qualitative "colorblind"
Ordered low to high sequential "viridis", "BuGn"
Above and below a midpoint diverging "vlag" with center=0
Highlight one item grey plus one accent GREY and AMBER

Common mistake. Typing the annotation text by hand ("Peak in December") and then refreshing the data. The label stays and the peak moves. Build labels from computed values.

#5.9 Saving figures

plt.savefig("name.png", dpi=130) writes the file. dpi is dots per inch, so 10 inches x 130 is 1300 pixels wide; use 130 for notebooks and 200 or more for print. Use .png for slides and reports and .svg or .pdf when you need crisp vector graphics. Add bbox_inches="tight" if long labels are clipped, and always plt.close() in loops so figures do not pile up in memory.

fig, ax = plt.subplots(figsize=(6, 2.5))
ax.plot([1, 2, 3], [2, 4, 3], color=BLUE)
ax.set_title("A throw-away chart")
fig.savefig("p05_tiny.png", dpi=100, bbox_inches="tight")
fig.savefig("p05_tiny.svg", bbox_inches="tight")
plt.close(fig)
for f in ["p05_tiny.png", "p05_tiny.svg"]:
    print(f, "exists:", os.path.exists(f), "| not empty:", os.path.getsize(f) > 0)

p05_tiny.png exists: True | not empty: True
p05_tiny.svg exists: True | not empty: True

Common mistake. With plt.show() or plt.close() called first, the figure is gone and plt.savefig writes a blank canvas. Save first, close second. The simplest safe habit is fig.savefig(...) on the figure object itself.

#5.10 Common chart mistakes

Most misleading charts are not lies, they are shortcuts. Learn to spot these in your own work first.

Mistake Why it misleads Fix
Truncated bar axis bar length no longer matches value start at zero
3D bars and pies perspective distorts size flat 2D charts
Pie with many slices angles are hard to compare sorted bar
Dual y axes scales can fake a correlation two panels sharing x
Cherry-picked window start date chosen to show a trend show the full period 
vals = pd.Series({"Branch A": 97.0, "Branch B": 98.5, "Branch C": 99.2})
fig, ax = plt.subplots(1, 2, figsize=(10, 3.3))
for a, floor, col, ttl in [(ax[0], 96, AMBER, "Misleading: axis starts at 96"),
                           (ax[1], 0, BLUE, "Honest: axis starts at 0")]:
    a.bar(vals.index, vals.values, color=col)
    a.set_ylim(floor, 100)
    a.set_title(ttl); a.set_xlabel("Branch"); a.set_ylabel("On-time delivery (%)")
plt.tight_layout(); plt.savefig("p05_axis_crime.png", dpi=130); plt.close()
print("C looks", round((99.2 - 96) / (97.0 - 96), 1), "x taller than A on the left; real ratio:",
      round(99.2 / 97.0, 3))

C looks 3.2 x taller than A on the left; real ratio: 1.023

On the left, branch C's bar looks several times taller than A's, though the real gap is about two percentage points. A truncated axis is acceptable on a line chart, where position rather than length carries the value, as long as the axis is labelled.

#5.11 Charts from real public data

Real data adds two things a tidy example never has: awkward values and a duty to be honest about what the chart shows. Here the recipe is applied to World Bank GDP, population and inflation and to the Our World in Data CO2 file.

Data note. World Bank series via datahub.io (GDP NY.GDP.MKTP.CD, CC BY 4.0; inflation FP.CPI.TOTL.ZG and population SP.POP.TOTL, ODC-PDDL) and the Our World in Data CO2 dataset (CC BY 4.0; Global Carbon Project). What we changed: kept countries only (the files also hold aggregates such as 'World'), renamed columns, merged on country code and year, and computed GDP per person. GDP is in current US dollars, not adjusted for price changes; inflation is the annual average change in consumer prices.

The distribution is skewed: most countries sit at low single-digit inflation and a few extreme cases stretch the right tail. Those cases are gathered in one capped bar instead of stretching the axis, and the median is a better centre than the mean.

Checklist for real data. 1) Say where the data comes from and what you changed. 2) Use log axes when values span orders of magnitude, and say so. 3) Cap or annotate extreme values instead of letting one country squash the rest. 4) Keep bar baselines at zero. 5) Describe association, not cause.

Key takeaways
  • Every chart starts with a question; the title states what is measured and when, and axes carry units.
  • Line = change over time, bar = compare categories (from zero), histogram and box = distribution, scatter = relationship.
  • Use fig, ax = plt.subplots() (object style), share axes in small multiples, and save before you close.
  • Seaborn draws grouped statistical plots in one line; split by group before you trust a correlation.
  • Highlight one thing in amber and build labels from the data; check charts in greyscale.
  • Avoid truncated bars, many-slice pies and dual axes; with real data, cite the source and avoid claiming cause.
