#22.1 Can-do checklist by level

Tick an item only when you can do it without notes. If you can tick most items at a level, move up.

Level You can...
1 Foundations Write a function; read a CSV; explain lists, dictionaries and loops; use NumPy arrays and boolean masks
2 Data Analysis Clean a messy table with a row-count log; merge tables without inflating rows; write a GROUP BY and a window function; make an honest chart
3 Statistics Build a confidence interval; pick and run the right test; explain a p-value and an effect size
4 Machine Learning Split data without leakage; fit and compare models; explain overfitting; choose metrics; tune with cross-validation; cluster and reduce dimensions
5 Deep Learning and AI Train a small neural network; explain attention, tokens and RAG; describe how Q-learning learns
6 The Real World Reconcile numbers across Python, SQL and Power BI; save and serve a model; check for drift and bias
7 Career Explain one project in three minutes using situation, task, action, result

#22.2 The algorithm chooser

Start with the simplest model that could work, set a baseline, and add complexity only when it earns its place.

Problem Try first Then Works best when Watch out for
Predict a number Linear regression Random forest, gradient boosting Relationship is roughly linear, or tabular data with interactions Outliers, extrapolation
Predict a category Logistic regression Random forest, gradient boosting, SVM Clear features and enough labelled rows Imbalanced classes, leakage
Few rows, many features Ridge or lasso SVM Regularisation helps Scaling
Find groups K-means DBSCAN, hierarchical, Gaussian mixture Groups are compact and features scaled Choosing k, outliers
Compress features PCA t-SNE for plots Features are correlated Interpretability
Spot unusual rows Isolation forest LOF, autoencoder Anomalies are rare and different No labels to validate
Images, audio, text Pretrained neural network Fine-tune a small network Lots of data or a good pretrained model Compute, overfitting
Decide a sequence of actions Bandits Q-learning You can simulate feedback Reward design, safety
Write or summarise text A large language model RAG over your documents Language tasks, drafts a person checks Hallucination, privacy

#scikit-learn pattern

Almost every model follows the same four steps: create, fit, predict, score.

from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X, y = load_wine(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=500))   # 1 create
model.fit(X_tr, y_tr)                                                      # 2 fit
pred = model.predict(X_te)                                                 # 3 predict
print("test accuracy:", round(model.score(X_te, y_te), 3), "| predictions:", pred[:8])  # 4 score

test accuracy: 1.0 | predictions: [0 1 0 0 1 0 0 1]

#Choosing a metric

Problem Metric Use when
Regression MAE, RMSE, R2 MAE for typical error; RMSE punishes big misses
Classification Accuracy Classes are balanced
Classification Precision, recall, F1 Classes are imbalanced or errors have different costs
Classification ROC AUC, PR AUC You rank cases or choose a threshold later
Clustering Silhouette No labels are available

#22.4 Glossary

Term Meaning
Feature An input column the model learns from.
Target (label) The value you want to predict.
Model A function that maps features to a prediction.
Training Adjusting a model's parameters to fit data.
Inference Using a trained model to predict for new data.
Hyperparameter A setting you choose before training, such as tree depth.
Loss function A number measuring how wrong predictions are.
Overfitting Memorising training noise, so new data scores badly.
Underfitting A model too simple to capture the pattern.
Bias-variance trade-off Simple models miss patterns (bias); flexible ones chase noise (variance).
Cross-validation Rotating which part of the data is held out to test the model.
Data leakage Information from the future or the answer sneaking into the features.
Regularisation A penalty that keeps a model simple.
Supervised learning Learning from labelled examples.
Unsupervised learning Finding structure without labels.
Reinforcement learning Learning actions by trial, reward and penalty.
Clustering Grouping similar rows.
Dimensionality reduction Compressing many features into fewer.
Neural network Layers of simple units trained by gradient descent.
Gradient descent Repeatedly nudging parameters to reduce the loss.
Epoch One full pass over the training data.
Embedding A list of numbers that represents a word, image or item.
Transformer A neural network built around attention.
Large language model A transformer trained on huge text to predict the next token.
Prompt The instructions and context you give a language model.
RAG Retrieval-augmented generation: fetch documents, then answer from them.
Hallucination A fluent answer that is false.
p-value How surprising the data would be if the null hypothesis were true.
Confidence interval A range of plausible values for the true quantity.
Effect size How big a difference is, apart from whether it is statistically detectable.
Grain What one row of a table represents.
Reconciliation Proving two sources give the same total.
PD / LGD / EAD Probability of default, loss given default, exposure at default.

#22.5 Where to go next

  • Repeat the projects in Part 19 with your own or public data and publish them.
  • Read the documentation of scikit-learn, pandas and PyTorch; it is excellent.
  • Join a local data community and present one project.
  • Pick a specialty: credit risk, forecasting, NLP, or computer vision.
Key takeaways
  • Use the can-do checklist to decide when to move up a level.
  • Start simple, set a baseline, then add complexity.
  • Every scikit-learn model follows create, fit, predict, score.
  • Choose the metric that matches the real cost of mistakes.
