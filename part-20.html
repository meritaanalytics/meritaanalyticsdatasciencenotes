#20.2 Python (E1 to E6)

# Question Expected result
E1 An illustrative mobile-money fee: Ksh 0 up to 100, Ksh 11 up to 1,000, Ksh 29 up to 5,000, else Ksh 50. Write fee(amount). What is fee(1500)? 29
E2 Matatu fares {'CBD': 50, 'Ruiru': 80, 'Thika': 120}. Add a 20 percent peak surcharge with a dict comprehension. Fare to Ruiru? 96.0
E3 Loan of Ksh 50,000 grows 2 percent a month for 3 months (compound). Final amount, 2 decimals? 53060.4
E4 BMI = kg / m^2. For (70, 1.75), (95, 1.70), (58, 1.80), (82, 1.65) count people with BMI of 25 or more. 2
E5 Which word is most common in 'send send money pay bill send airtime pay'? send (3)
E6 Write safe_float(text) that turns '1,250' into 1250.0 and returns None for 'n/a'. 1250.0 and None

Hints. E1: if / elif / else. E3: x * (1 + r) ** n. E4: list comprehension with a condition. E5: collections.Counter. E6: try / except ValueError and replace(',', '').

#Answer key

def fee(amount):
    if amount <= 100:
        return 0
    elif amount <= 1000:
        return 11
    elif amount <= 5000:
        return 29
    return 50

assert fee(1500) == 29 and fee(100) == 0 and fee(9000) == 50
ok("E1", fee(1500))

fares = {"CBD": 50, "Ruiru": 80, "Thika": 120}
peak = {k: v * 1.2 for k, v in fares.items()}
assert round(peak["Ruiru"], 1) == 96.0
ok("E2", round(peak["Ruiru"], 1))

final = round(50000 * (1 + 0.02) ** 3, 2)
assert final == 53060.4
ok("E3", final)

E1 ok 29
E2 ok 96.0
E3 ok 53060.4
from collections import Counter

people = [(70, 1.75), (95, 1.70), (58, 1.80), (82, 1.65)]
n_high = sum(1 for kg, m in people if kg / m**2 >= 25)
assert n_high == 2
ok("E4", n_high)

word, times = Counter("send send money pay bill send airtime pay".split()).most_common(1)[0]
assert (word, times) == ("send", 3)
ok("E5", word, times)

def safe_float(text):
    try:
        return float(text.replace(",", ""))
    except ValueError:
        return None

#20.5 Statistics (E20 to E25)

# Question Expected result
E20 Incomes (Ksh thousands) [20, 22, 25, 27, 30, 400]. Is the mean above or below the median? By how much? mean 87.3 > median 26.0
E21 Marks are normal with mean 60 and sd 5. Probability of a mark above 70, 4 decimals? 0.0228
E22 A 95 percent t-confidence interval for the mean of [48, 52, 50, 55, 47, 51, 53, 49]. Does it contain 50? yes
E23 Two seeded samples of loan sizes, group A mean 10 and group B mean 12 (n=60, sd=3). Test the difference. p below 0.05
E24 Is repayment (yes/no) linked to channel (app/agent)? Table [[40, 10], [25, 25]]. Chi-square test. p below 0.05
E25 A fraud rule catches 90 percent of fraud (sensitivity) and wrongly flags 5 percent of honest cases. Fraud is 1 percent of cases. Chance a flagged case is real? 0.1538

Hints. E20: np.mean versus np.median. E21: scipy.stats.norm.sf. E22: stats.t.interval with stats.sem. E23: stats.ttest_ind (use equal_var=False). E24: stats.chi2_contingency. E25: Bayes' rule, P(fraud | flag) = P(flag | fraud) x P(fraud) / P(flag).

#Answer key

from scipy import stats

inc = np.array([20, 22, 25, 27, 30, 400])
assert inc.mean() > np.median(inc) and round(inc.mean(), 1) == 87.3 and np.median(inc) == 26.0
ok("E20", round(inc.mean(), 1), np.median(inc))

p21 = round(stats.norm.sf(70, loc=60, scale=5), 4)
assert p21 == 0.0228
ok("E21", p21)

x = np.array([48, 52, 50, 55, 47, 51, 53, 49])
lo, hi = stats.t.interval(0.95, df=len(x) - 1, loc=x.mean(), scale=stats.sem(x))
assert lo < 50 < hi
ok("E22", round(lo, 2), round(hi, 2))

E20 ok 87.3 26.0
E21 ok 0.0228
E22 ok 48.39 52.86
rng = np.random.default_rng(42)
a = rng.normal(10, 3, 60)
b = rng.normal(12, 3, 60)
t_stat, p23 = stats.ttest_ind(a, b, equal_var=False)
assert p23 < 0.05 and a.mean() < b.mean()
ok("E23", "p =", round(p23, 4))

assert p24 < 0.05 and dof == 1
ok("E24", "p =", round(p24, 4))

sens, fpr, prev = 0.90, 0.05, 0.01

E25 is the base-rate effect: when fraud is rare, most flags are false alarms even for a good rule. This is why a flagged case goes to a person for review before any action.

# Question Expected result
E26 Build a majority-class baseline. Does a logistic regression beat its test accuracy? True
E27 Put a scaler and a logistic regression in a Pipeline and run 5-fold cross-validation. Is the mean score above 0.9? Why must the scaler sit inside the pipeline? True
E28 Fit an unlimited-depth decision tree. Show that train accuracy is higher than test accuracy, then show a depth-3 tree has a smaller gap. True and True

Hints. E26: DummyClassifier(strategy='most_frequent'). E27: make_pipeline(StandardScaler(), ...) and cross_val_score. E28: gap = train score minus test score.

#Answer key

from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier

base = DummyClassifier(strategy="most_frequent").fit(X_tr, y_tr)
logit = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)).fit(X_tr, y_tr)
beat = logit.score(X_te, y_te) > base.score(X_te, y_te)
assert beat
ok("E26", "baseline", round(base.score(X_te, y_te), 3), "logit", round(logit.score(X_te, y_te), 3))

cv = cross_val_score(make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)), X, y, cv=5)
assert cv.mean() > 0.9
ok("E27", round(cv.mean(), 3))
# inside the pipeline the scaler is re-fitted on each training fold only, so no test-fold information leaks.

def gap(depth):
    t = DecisionTreeClassifier(max_depth=depth, random_state=42).fit(X_tr, y_tr)
    return t.score(X_tr, y_tr) - t.score(X_te, y_te)

assert gap(None) > 0 and gap(3) < gap(None)
ok("E28", "gap deep", round(gap(None), 3), "gap depth 3", round(gap(3), 3))

E26 ok baseline 0.629 logit 0.986
E27 ok 0.981
E28 ok gap deep 0.077 gap depth 3 0.032

#20.8 Unsupervised learning (E33 to E34)

# Question Expected result
E33 Generate 3 well-separated blobs. For k = 2 to 6 compute the silhouette score. Which k is best? 3
E34 Scale the wine dataset and run PCA. How many components keep at least 90 percent of the variance? a small whole number (printed)

Hints. E33: make_blobs(random_state=42), KMeans(n_clusters=k, n_init=10), silhouette_score. E34: np.cumsum(pca.explained_variance_ratio_) and argmax.

#Answer key

from sklearn.datasets import make_blobs, load_wine
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.decomposition import PCA

Xb, _ = make_blobs(n_samples=300, centers=3, cluster_std=0.8, random_state=42)
scores = {k: silhouette_score(Xb, KMeans(n_clusters=k, n_init=10, random_state=42).fit_predict(Xb))
          for k in range(2, 7)}
best_k = max(scores, key=scores.get)
assert best_k == 3
ok("E33", best_k, {k: round(v, 2) for k, v in scores.items()})

Xw, _ = load_wine(return_X_y=True)
pca = PCA().fit(StandardScaler().fit_transform(Xw))
cum = np.cumsum(pca.explained_variance_ratio_)
n90 = int(np.argmax(cum >= 0.90)) + 1
assert cum[n90 - 1] >= 0.90 and (n90 == 1 or cum[n90 - 2] < 0.90)
ok("E34", n90, "components keep", round(cum[n90 - 1], 3))

E33 ok 3 {2: 0.72, 3: 0.88, 4: 0.7, 5: 0.5, 6: 0.33}
E34 ok 8 components keep 0.92

#20.9 Deep learning concepts (E35 to E36)

# Question Expected result
E35 By hand in NumPy, compute the forward pass of a 2-input, 2-hidden (ReLU), 1-output network with given weights. Does it equal the PyTorch result? True
E36 Train a tiny PyTorch network on the XOR pattern for a few hundred steps. Does the loss fall a lot? True

Hints. E35: hidden = relu(x @ W1 + b1), output = hidden @ W2 + b2. For PyTorch, copy the same numbers into nn.Linear weights (a Linear layer stores weights as out x in). E36: nn.Sequential, nn.MSELoss, torch.optim.Adam, a loop of forward, loss, backward, step.

#Answer key

import torch
from torch import nn
torch.set_num_threads(2)

W1 = np.array([[1.0, -1.0], [0.5, 2.0]]); b1 = np.array([0.0, 0.5])
W2 = np.array([[2.0], [1.0]]);            b2 = np.array([-1.0])
x = np.array([[1.0, 2.0]])
by_hand = np.maximum(x @ W1 + b1, 0) @ W2 + b2

l1, l2 = nn.Linear(2, 2), nn.Linear(2, 1)
with torch.no_grad():
    l1.weight.copy_(torch.tensor(W1.T, dtype=torch.float32)); l1.bias.copy_(torch.tensor(b1, dtype=torch.float32))
