#How to study with it

  • Read a section, then run its code cell and change one thing. Learning happens when you edit.
  • Do the practice question before you read its solution.
  • Each part starts with what you will learn and ends with key takeaways. If you cannot say the takeaways in your own words, re-read.
  • Sections marked (Advanced) can wait. Skip them on a first pass and return later.
  • Plan about 8 to 10 hours a week. The suggested path in Part 1 takes 32 weeks.

#About the data in this handbook

Kind What it is Where to find it
Public data Real, openly licensed data: World Bank, Our World in Data, Palmer penguins, and the small datasets bundled with scikit-learn. datasets/public/ and Appendix B (source, licence, link)
Synthetic data Data invented by code with fixed random seeds, used where real data is confidential, such as lending, M-Pesa and insurance records. It describes no real person or company. Generated by the notebook; copies in datasets/synthetic/; Appendix B
  • Findings on synthetic data describe the synthetic data only.
  • Tax, interest and risk figures are illustrative, not current KRA or CBK rules.
  • Model scores can differ slightly on another computer or library version; the ideas stay the same.

#Set up your computer (about 20 minutes)

Step What to do
1 Install Python 3.12 or newer from python.org and tick Add python.exe to PATH.
2 Install VS Code with the Python and Jupyter extensions (or use JupyterLab).
3 In a project folder create an environment: python -m venv .venv, then activate it.
4 Install the tools: python -m pip install numpy pandas matplotlib seaborn scipy statsmodels scikit-learn xgboost lightgbm torch jupyterlab openpyxl.
5 Open the notebook. Use Kernel, Restart and Run All to confirm everything runs top to bottom. 
import platform
import numpy as np, pandas as pd, matplotlib, scipy, sklearn
print("Python", platform.python_version())
for m in (np, pd, matplotlib, scipy, sklearn):
    print(m.__name__, m.__version__)
