#2.1 What a program is, and how to run Python

A program is a list of instructions that a computer follows from top to bottom. Python is a programming language that reads like plain English, which is why most data scientists use it. You write instructions, Python runs them, and you see the result.

The easiest place to learn is a Jupyter notebook. A notebook is a page made of cells. A code cell holds Python; you run it with Shift+Enter and the result appears right under it. Text cells hold notes. Cells share memory, so a value created in one cell can be used in the cells below it.

print("Habari, Nairobi!")
2 + 3

Habari, Nairobi!
5

print() shows a value on the screen. If the last line of a cell is just a value, the notebook shows it automatically. Anything after a # is a comment: a note for humans that Python ignores.

# a comment: Python skips this line
fare = 50      # matatu fare in Ksh
print(fare * 2)

100

Common mistake. Run cells from top to bottom. If you change a cell, run it again, and run the cells below it, otherwise they still use the old values.

#2.2 Variables, types and numbers

A variable is a name that points to a value. You create it with =. Python works out the type of the value for you. The four basic types are int (whole numbers), float (decimals), str (text) and bool (True or False).

shop = "Mama Njeri Stores"
items_in_stock = 120
price = 85.5
is_open = True
for v in (shop, items_in_stock, price, is_open):
    print(v, "->", type(v).__name__)

Mama Njeri Stores -> str
120 -> int
85.5 -> float
True -> bool

Variable names use letters, digits and underscores, cannot start with a digit, and are case sensitive. Pick names that say what the value means (unit_price, not x).

#Arithmetic

Operator Meaning Example Result
+ - * add, subtract, multiply 7 * 3 21
/ divide (always a float) 7 / 2 3.5
// whole-number division 7 // 2 3
% remainder 7 % 2 1
** power 2 ** 3 8

Here is a loan example. A SACCO lends Ksh 50,000 at 12 percent a year for one year, with simple interest.

principal = 50000
rate = 0.12
interest = principal * rate
total = principal + interest
monthly = total / 12
print(f"Interest: Ksh {interest:,.0f}")
print(f"Total to repay: Ksh {total:,.0f}")
print(f"Monthly instalment: Ksh {monthly:,.2f}")

Interest: Ksh 6,000
Total to repay: Ksh 56,000
Monthly instalment: Ksh 4,666.67

Useful built-ins for numbers are round(x, 2), abs(x), min(), max(), sum() and divmod(a, b) (quotient and remainder together). Use int("42") and float("3.5") to convert text to numbers.

print(round(2 / 3, 3), abs(-40), divmod(1250, 100))
print(0.1 + 0.2)

0.667 40 (12, 50)
0.30000000000000004

Good to know. Decimals are stored in binary, so 0.1 + 0.2 is not exactly 0.3. This is normal in every language. Round for display and never compare floats with ==.

#2.3 Strings and f-strings

A string is text inside quotes. Strings come with many methods, which are actions written after a dot, such as .upper(). Strings are immutable: a method returns a new string and never changes the original.

name = "  wanjiru kamau  "
print(name.strip().title())
print(name.upper().strip())
print("kamau" in name, len(name.strip()))
print("m-pesa,airtel money,t-kash".split(","))
print("2025-03-14".replace("-", "/"))

Wanjiru Kamau
WANJIRU KAMAU
True 13
['m-pesa', 'airtel money', 't-kash']
2025/03/14

The most useful tool is the f-string: put f before the quotes and place variables inside braces. After a colon you can format the value: :, adds thousands commas, .2f keeps two decimals and .1% turns 0.125 into 12.5%.

customer, balance, rate = "Otieno", 1234567.891, 0.125
print(f"{customer} has Ksh {balance:,.2f}")
print(f"Interest rate: {rate:.1%}")
print(f"{'Item':<10}{'Qty':>5}")
print(f"{'Sugar':<10}{40:>5}")

Otieno has Ksh 1,234,567.89
Interest rate: 12.5%
Item        Qty
Sugar        40

Here <10 pads to ten characters aligned left and >5 aligns right in five. Joining text uses + or ", ".join(list_of_text).

Common mistake. You cannot add text to a number: "Total: " + 500 fails. Use an f-string: f"Total: {500}".

Practice

format 0.0825 as a percent with two decimals.

Show solution

f"{0.0825:.2%}" gives 8.25%.

#2.4 True/False, comparisons and if/elif/else

A Boolean is True or False. You get one by comparing values with == (equal), != (not equal), <, >, <=, >=. Combine tests with and, or and not. Remember that = stores a value but == asks a question.

stock, reorder_level = 8, 10
print(stock < reorder_level)
print(stock > 0 and stock < reorder_level)
print(not (stock == 0))

True
True
True

An if statement runs code only when a test is True. Add elif (else if) for more tests and else for everything left over. Python checks from the top and stops at the first True. The indented lines (four spaces) after the colon belong to that branch; indentation is how Python knows.

Example: an illustrative M-Pesa send-money fee table (not real rates). Order the tests carefully, because the first match wins.

amount = 450
if amount <= 100:
    fee = 0
elif amount <= 500:
    fee = 7
elif amount <= 1000:
    fee = 13
elif amount <= 5000:
    fee = 30
else:
    fee = 60
print(f"Send Ksh {amount:,}: fee Ksh {fee}")

Send Ksh 450: fee Ksh 7

Change amount to 80, 1000, 3200 and 20000 and run again to see the other branches (section 2.8 turns this into a reusable function).

Common mistake. Putting a wide test first (such as amount <= 5000) would catch every small amount and hide the narrower tests below it. Order tests from most specific to most general.

#2.5 Lists, tuples, sets and dictionaries

Real data comes in groups, so Python has four collections. Choose by what you need.

Type Written Ordered Can change Use it for
list [1, 2, 3] yes yes a sequence of values
tuple (1, 2, 3) yes no a fixed record, such as a point
set {1, 2, 3} no yes unique values, membership tests
dict {"a": 1} yes yes look up a value by a key

#Lists

fares = [50, 70, 100]
fares.append(120)
fares.insert(0, 30)
fares.remove(70)
print(fares, len(fares), sum(fares), max(fares))
print(sorted(fares, reverse=True))

[30, 50, 100, 120] 4 300 120
[120, 100, 50, 30]

#Tuples and sets

location = (-1.286, 36.817)          # latitude, longitude: should not change
lat, lon = location                  # unpacking
counties = {"Nairobi", "Kiambu", "Nairobi", "Nakuru"}
print(lat, lon)
print(counties, len(counties))
print("Kiambu" in counties)

-1.286 36.817
{'Kiambu', 'Nakuru', 'Nairobi'} 3
True

A set drops duplicates, which makes it a quick way to find unique values. Sets also support a & b (in both) and a | b (in either).

#Dictionaries

A dictionary stores key: value pairs. It is the Python version of a lookup table, and it is the shape of one row of data.

stock = {"sugar": 40, "maize flour": 25, "cooking oil": 12}
stock["rice"] = 30                      # add
stock["sugar"] -= 5                     # change
print(stock["sugar"], stock.get("tea", 0))
for item, qty in stock.items():
    print(f"{item:<12}{qty:>4}")
print(list(stock.keys()))

35 0
sugar         35
maize flour   25
cooking oil   12
rice          30
['sugar', 'maize flour', 'cooking oil', 'rice']

Use .get(key, default) when a key might be missing, so you get a default instead of an error. Dictionaries can hold lists and other dictionaries, which is exactly how JSON files are built (section 2.9).

#2.6 Indexing and slicing

Indexing picks one item by its position. Positions start at 0, and negative positions count from the end (-1 is the last). Slicing picks a range with [start:stop:step]; it includes start and excludes stop. This works the same for lists, tuples and strings.

marks = [72, 55, 88, 64, 91, 47]
print(marks[0], marks[-1])
print(marks[1:4])
print(marks[:3], marks[3:])
print(marks[::2], marks[::-1])
print("Nairobi"[0:3])

72 47
[55, 88, 64]
[72, 55, 88] [64, 91, 47]
[72, 88, 91] [47, 91, 64, 88, 55, 72]
Nai

A good way to remember: a slice [1:4] gives positions 1, 2 and 3, and stop - start is its length. These same ideas return in NumPy (Part 3) and pandas (Part 4).

Common mistake. A list of 6 items has positions 0 to 5. Asking for marks[6] raises an IndexError.

Practice

#2.7 Loops and list comprehensions

A loop repeats code. A for loop visits each item of a collection. range(n) gives the numbers 0 to n-1, and enumerate() gives the position together with the item.

fares = {"Rongai": 80, "Kikuyu": 60, "Githurai": 50}
total = 0
for stage, fare in fares.items():
    total += fare
    print(f"{stage:<9} Ksh {fare}")
print("Total:", total)
for i, stage in enumerate(fares, start=1):
    print(i, stage)

Rongai    Ksh 80
Kikuyu    Ksh 60
Githurai  Ksh 50
Total: 190
1 Rongai
2 Kikuyu
3 Githurai

A while loop repeats while a test stays True. Be sure something inside changes the test, or it never stops. break leaves the loop early and continue skips to the next round.

balance, month = 10000, 0
while balance < 15000:
    balance *= 1.05            # grows 5 percent a month
    month += 1
print(month, round(balance))

9 15513

#List comprehensions

A list comprehension builds a new list in one line: [expression for item in collection if test]. It is a short form of a for loop that appends to a list.

marks = [72, 55, 88, 64, 91, 47]
passed = [m for m in marks if m >= 50]
scaled = [round(m / 100 * 20, 1) for m in marks]
print(passed)
print(scaled)
print({m: ("pass" if m >= 50 else "fail") for m in marks[:3]})

[72, 55, 88, 64, 91]
[14.4, 11.0, 17.6, 12.8, 18.2, 9.4]
{72: 'pass', 55: 'pass', 88: 'pass'}

The last line is a dictionary comprehension. Keep comprehensions short; when the logic needs several steps, use a normal loop so it stays readable.

Practice

make a list of the squares of the even numbers from 1 to 10.

Show solution

[n**2 for n in range(1, 11) if n % 2 == 0] gives [4, 16, 36, 64, 100].

#2.8 Functions and lambdas

A function is a named, reusable block of code. You define it with def, give it parameters (inputs), and send a result back with return. Functions stop you repeating yourself and make code easy to test.

def mpesa_fee(amount):
    if amount <= 100:
        return 0
    elif amount <= 500:
        return 7
    elif amount <= 1000:
        return 13
    elif amount <= 5000:
        return 30
    return 60

for amt in [80, 450, 1000, 3200, 20000]:
    print(f"Send Ksh {amt:>6,}: fee Ksh {mpesa_fee(amt)}")

Send Ksh     80: fee Ksh 0
Send Ksh    450: fee Ksh 7
Send Ksh  1,000: fee Ksh 13
Send Ksh  3,200: fee Ksh 30
Send Ksh 20,000: fee Ksh 60

Parameters can have default values, and you can call a function with names for clarity. A function with no return gives back None.

def loan_total(principal, rate=0.12, years=1):
    """Total repayable with simple interest."""
    return round(principal * (1 + rate * years), 2)

print(loan_total(50000))
print(loan_total(50000, years=2))
print(loan_total(rate=0.15, principal=20000))

56000.0
62000.0
23000.0

Variables created inside a function are local: they exist only while it runs. Return what you need rather than relying on outside variables.

#Lambdas

A lambda is a tiny unnamed function written on one line: lambda x: x * 2. They are handy as a throw-away rule, for example to sort or to apply a calculation.

vat = lambda price: price * 1.16
print(round(vat(1000), 2))
shops = [("Kasarani", 340), ("Rongai", 510), ("Thika", 275)]
print(sorted(shops, key=lambda s: s[1], reverse=True))
print(list(map(lambda s: s[0].upper(), shops)))

1160.0
[('Rongai', 510), ('Kasarani', 340), ('Thika', 275)]
['KASARANI', 'RONGAI', 'THIKA']

Common mistake. Forgetting return is a classic slip: the function prints its answer but gives back None, so later calculations fail. If you need the value again, return it.

#2.9 Modules, files and dates

#Importing modules

A module is a file of ready-made Python code, and a library is a bundle of modules. import brings one in. The standard library ships with Python; others such as NumPy are installed with pip. You can give a module a short alias with as.

import math
import statistics as st
from random import Random
print(math.sqrt(144), math.ceil(7.2), round(math.pi, 4))
print(st.mean([72, 55, 88, 64]), st.median([72, 55, 88, 64]))
print(Random(42).choice(["Nairobi", "Mombasa", "Kisumu"]))

12.0 8 3.1416
69.75 68.0
Kisumu

#Reading and writing files

Use pathlib.Path for file locations and the with statement to open files, because with closes the file for you. The csv module reads rows of a spreadsheet-style file, and json handles nested data made of dictionaries and lists. For big tables you will use pandas instead (Part 4).

from pathlib import Path
import csv, json

Path("p02_data").mkdir(exist_ok=True)
rows = [("sugar", 40, 180), ("maize flour", 25, 150), ("cooking oil", 12, 320)]
with open("p02_data/stock.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["item", "qty", "price"])
    w.writerows(rows)

with open("p02_data/stock.csv") as f:
    for row in csv.DictReader(f):
        print(row["item"], int(row["qty"]) * int(row["price"]))

cooking oil 3840

back = json.loads(Path("p02_data/shop.json").read_text())
print(back["items"], Path("p02_data/shop.json").exists())

#Dates and times

The datetime module has date for calendar days, datetime for date plus time and timedelta for a gap between them. Turn text into a date with strptime, and a date into text with strftime.

from datetime import date, datetime, timedelta
issued = datetime.strptime("2025-03-14", "%Y-%m-%d").date()
due = issued + timedelta(days=90)
print(due, due.strftime("%d %B %Y"), due.strftime("%A"))
print((date(2025, 12, 25) - issued).days, "days between")

2025-06-12 12 June 2025 Thursday
286 days between

Common format codes: %Y year, %m month number, %d day, %B month name, %A weekday name, %H:%M hours and minutes.

#2.10 Reading error messages

Every programmer sees errors daily. An error is Python telling you what went wrong, so read it from the bottom: the last line names the error type and the reason; the lines above show where. Fix the first error you see, then run again.

stock = {"sugar": 40}
print(stock["tea"])
Error on purposeKeyError: 'tea'
total = "Total: " + 500
Error on purposeTypeError: can only concatenate str (not "int") to str

The first shows a KeyError (the key tea does not exist) and the second a TypeError (text and a number cannot be added). These are the six errors you will meet most often:

Error Usual cause Fix
SyntaxError missing colon, bracket or quote check the line shown and the one before it
NameError variable not defined, a typo, or a cell not run fix the spelling; run the earlier cell
TypeError mixing types, e.g. text plus number convert with str(), int() or an f-string
ValueError right type, bad value, e.g. int("abc") clean or check the input first
KeyError / IndexError missing dictionary key or position use .get(); check len()
IndentationError inconsistent spaces after a colon use four spaces everywhere

To handle an error that you expect, wrap the risky line in try and except. Catch the specific error type, not everything.

for text in ["250", "1,200", "abc"]:
    try:
        amount = int(text.replace(",", ""))
        print("OK", amount)
    except ValueError:
        print("Cannot read", repr(text))

OK 250
OK 1200
Cannot read 'abc'

When stuck: read the last line, look at the line number, print the variables involved and search the error text.

#2.11 Mini project: a shop stock report

Let us combine everything. In this synthetic example a small shop keeps prices in a dictionary and daily stock in a CSV file. The report lists stock value, flags items to reorder and totals the shop. Steps: create the data, read it, compute, then print a report.

import csv
from pathlib import Path

prices = {"sugar": 180, "maize flour": 150, "cooking oil": 320, "rice": 210, "tea leaves": 95}
reorder_at = 15
lines = ["item,qty", "sugar,40", "maize flour,12", "cooking oil,9", "rice,30", "tea leaves,6"]
Path("p02_stock_today.csv").write_text("\n".join(lines))
print(len(lines) - 1, "items in the file")

5 items in the file
def stock_report(csv_path, prices, reorder_at):
    report, total = [], 0
    with open(csv_path) as f:
        for row in csv.DictReader(f):
            qty = int(row["qty"])
            value = qty * prices[row["item"]]
            total += value
            report.append((row["item"], qty, value, qty < reorder_at))
    return report, total

report, total = stock_report("p02_stock_today.csv", prices, reorder_at)
print(f"{'Item':<13}{'Qty':>5}{'Value (Ksh)':>13}  Status")
for item, qty, value, low in report:
    print(f"{item:<13}{qty:>5}{value:>13,}  {'REORDER' if low else 'ok'}")
print(f"Total stock value: Ksh {total:,}")

Item           Qty  Value (Ksh)  Status
sugar           40        7,200  ok
maize flour     12        1,800  REORDER
cooking oil      9        2,880  REORDER
rice            30        6,300  ok
tea leaves       6          570  REORDER
Total stock value: Ksh 18,750
to_buy = [item for item, qty, value, low in report if low]
print("Reorder:", ", ".join(to_buy))
best = max(report, key=lambda r: r[2])
print(f"Most valuable line: {best[0]} (Ksh {best[2]:,})")

Reorder: maize flour, cooking oil, tea leaves
Most valuable line: sugar (Ksh 7,200)

Extensions: save the reorder list to a JSON file, add a date to the report with datetime, or catch the KeyError when the CSV has an item missing from prices.

#2.12 (Advanced) Classes, recursion and virtual environments

#Classes

A class is a blueprint that bundles data (attributes) with actions (methods). __init__ runs when you create an object (an instance), and self refers to that object. You will use classes from libraries all the time (a pandas table is an object) even if you rarely write your own.

class Loan:
    def __init__(self, principal, rate, months):
        self.principal, self.rate, self.months = principal, rate, months
    def total(self):
        return self.principal * (1 + self.rate * self.months / 12)
    def instalment(self):
        return self.total() / self.months

loan = Loan(60000, 0.14, 6)
print(round(loan.total()), round(loan.instalment(), 2))

64200 10700.0

#Recursion

A recursive function calls itself on a smaller problem until it reaches a simple base case. Without a base case it never stops.

def total_savings(deposits):
    if not deposits:                  # base case: nothing left
        return 0
    return deposits[0] + total_savings(deposits[1:])
print(total_savings([500, 1200, 300, 800]))

2800

In practice a loop or sum() is usually simpler; recursion shines on nested data such as folders or trees.

#pip and virtual environments

pip installs libraries. A virtual environment is a private folder of libraries for one project, so projects do not break each other. Run these in a terminal (not in a notebook cell):

python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install pandas numpy matplotlib
pip freeze > requirements.txt      # record the versions you used

Not executed in this notebook (needs a service or setting you must provide yourself).

Anyone can rebuild your setup later with pip install -r requirements.txt.

Key takeaways
  • A program is a list of instructions; a notebook runs it cell by cell, top to bottom.
  • Variables name values; the basic types are int, float, str and bool.
  • Use f-strings to format output, for example f"Ksh {x:,.2f}".
  • Lists, tuples, sets and dicts hold groups of values; indexing starts at 0.
  • if/elif/else decide, loops repeat, and functions package logic you reuse.
  • Read errors from the last line up, and fix one at a time.
